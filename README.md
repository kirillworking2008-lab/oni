# ONI PLR Studio — Android (КИПиА Edition)

Полноценная автономная Android-копия среды программирования логических реле и микро-ПЛК **ONI PLR Studio** (IEK GROUP), созданная специально для обучения и ежедневной практики **слесарей и инженеров КИПиА** на планшете с клавиатурой и мышью (а также на любом Android-смартфоне) — **без Windows, без эмуляторов и полностью оффлайн**.

---

## 📦 Установка готового `.apk` на планшет / смартфон Android

1. Скачайте готовый подписанный файл **[`ONI-PLR-Studio-Android.apk`](./ONI-PLR-Studio-Android.apk)** из корня репозитория (или из раздела *Actions / Releases*).
2. Откройте файл на Android-устройстве в проводнике («Файлы») и подтвердите установку пакета **`ONI PLR Studio`** (`ru.oni.plrstudio`, Android 7.0 – Android 16).
3. Подключите к планшету клавиатуру и мышь (или управляйте пальцами / стилусом) и запускайте приложение — интернет для работы не требуется.

## ⚙️ Что реализовано внутри («1-в-1 как на ПК + инструменты КИПовца»)

### 1. Точная копия редактора и офлайн-симулятора **ONI PLR Studio (FBD)**
- Классическая раскладка окон настольной программы: главное меню (`Файл`, `Изменить`, `Инструменты`, `Вид`, `Обучение КИПиА`, `Справка`), верхняя панель инструментов, левая быстрая полоса (`Курсор`, `Соединение`, `Co`, `GF`, `SF`, `AF`, `A`, `✂`, `Симулятор`), дерево **«Библиотека блоков»** с поиском и сетчатое серое поле схемы.
- **34 функциональных блока ONI**:
  - **Цифровые (`Co`)**: `DI` (`I001..I016`), `DO` (`Q001..Q012`), меркеры `M`, кнопки панели реле `C1..C6`, константы `Hi` / `Lo`.
  - **Аналоговые (`Co`)**: `AI` (`0..10 В`, `4..20 мА`, `Pt100`), `AO` (`AQ001..AQ004`), регистры `AM`.
  - **Логические функции (`GF`)**: `И (AND)`, `И по фронту`, `И-НЕ (NAND)`, `И-НЕ по срезу`, `ИЛИ (OR)`, `ИЛИ-НЕ (NOR)`, `Исключающее ИЛИ (XOR)`, `НЕ (NOT)`, настраиваемая мажоритарная таблица «2 из 3» (`LUT`).
  - **Временные блоки (`SF`)**: `Задержка включения (TON)`, `Задержка выключения (TOF)`, `TON/TOF`, `Задержка с памятью (TONR)`, `Одновибратор (TP)`, `Генератор импульсов / мигалка (BLINK)`, `Серия импульсов (MPG)`, `Таймер продувки (STAIR)`, `Недельный таймер (WKT)`.
  - **Триггеры и счётчики (`SF`)**: `RS-триггер` (приоритет сброса СТОП), `SR-триггер`, `Импульсное реле (TL)`, `Реверсивный счётчик (CTUD)`, `Счётчик моточасов (OTM)`, `Частотомер (FRE)`.
  - **Аналоговые функции КИПиА (`AF`) и экран**: `Аналоговый пороговый выключатель с гистерезисом (ATRG)`, `Аналоговый компаратор (CMP)`, `Аналоговый усилитель / масштабирование (AMP)`, `Сторож обрыва токовой петли 4–20 мА (AWD)`, `ПИ-регулятор (PI)`, `Мультиплексор уставок (MUX)`, `Математика (MATH)`, `Плавный пуск (RAMP)`, `Текстовое сообщение ЖК-экрана реле (MSG)`.
- **Инверсия входа двойным кликом**: как в оригинальном ONI PLR Studio, двойной клик ЛКМ по входной ножке блока ставит кружок инверсии `○` (`НЕ`).
- **Офлайн-симулятор (`F3`)**: точная цветовая индикация (`Красный = ON / 1`, `Синий = OFF / 0`), режимы входов `Тумблер / Кнопка НО / Кнопка НЗ (для СТОП и тепловых реле КК1)`, регулировка токовой петли `4–20 мА`, имитация обрыва линии датчика (`< 3.6 мА`), экран реле 4×16, многоканальный **осциллограф КИПиА**, проверка ошибок `ERC` и живая таблица регистров **Modbus RTU**.
- Открытие и сохранение проектов `.oni.json`, совместимый импорт/экспорт `.xlg` и экспорт чертежа со штампом в `.svg`.

### 2. Редактор и симулятор релейно-контактных схем **LD / РКС (МЭК 61131-3)**
- Для чтения принципиальных схем Э3 и программирования ПЛК линейки ONI (CICON / Builder): шины питания, контакты `НО`, `НЗ`, фронты, параллельные шунты самоподхвата, катушки `( )`, `(S)`, `(R)`, таймеры и счётчики.

### 3. Виртуальный стенд объектов КИПиА + Панель HMI + Клеммник на DIN-рейке
- **4 живые физические модели технологических объектов** с обратной связью на входы реле:
  1. **Насосная станция и резервуар (КНС / ВНС)** — датчик уровня `4–20 мА`, коллектор давления, 2 насоса с АВР, реле протока `PDS`, сухой ход, имитация срыва подачи и обрыва кабеля датчика.
  2. **Промышленная термокамера / печь** — датчик `Pt100 / 4–20 мА`, тиристорный регулятор мощности ТЭНов `AQ1`, защитный термостат перегрева.
  3. **Приточная вентсистема ПВУ** — привод жалюзи с концевиком, дифманометр вентилятора и электрокалорифер с контролем продувки.
  4. **Конвейер дозирования и фасовки** — оптический датчик счёта тары и тензодатчик веса.
- **Интерактивный клеммник реле `ONI PLR-S-CPU-1206`** на DIN-рейке с памяткой расключения датчиков `4–20 мА`, `PNP` и пускателей.

### 4. Практикум КИПовца (10 задач с автопроверкой) и Полевая шпаргалка
- **10 реальных промышленных заданий** (от *Пуск-Стоп с НЗ кнопкой и тепловым реле КК1* и *Реверса электрозадвижки с блокировкой* до *Квитирования аварийной звуковой сигнализации*, *Продувки ТЭНов калорифера*, *Контроля обрыва 4–20 мА* и *АВР насосов по реле протока*) — с автоматическим прогоном тестового стенда по шагам.
- Встроенный **инженерный калькулятор токовой петли `4–20 мА ↔ физ. величина ↔ код АЦП ↔ Gain/Offset`** и справочник по подключению `Pt100`, `PNP/NPN`, настройке `ПИ-регулятора` и шины `RS-485 Modbus RTU`.

## 🖱 Управление на планшете (мышь + клавиатура + тач)

| Действие | Мышь / Клавиатура | Сенсорный экран |
|---|---|---|
| Установить блок | Выбрать в «Библиотеке блоков» → ЛКМ на схеме (или перетащить) | Тап по блоку в библиотеке → тап на листе |
| Соединить блоки проводом | Перетащить ЛКМ от выхода (справа) ко входу (слева) | Потянуть или нажать выход → нажать вход |
| Инверсия входа (`НЕ ○`) | Двойной клик ЛКМ по ножке входа (или ПКМ → Инвертировать) | Долгое нажатие по ножке → Инвертировать |
| Свойства блока (таймер, порог) | Двойной клик ЛКМ по блоку или `Enter` | Двойной тап или долгое нажатие → Свойства |
| Контекстное меню | Правая кнопка мыши (`ПКМ` — защищена от срабатывания «Назад»!) | Долгое нажатие пальцем (0,5 с) |
| Масштаб и панорамирование | Колесо мыши / `Пробел + ЛКМ` / Средняя кнопка мыши | Щипок двумя пальцами (Pinch-to-Zoom) |
| Симулятор ВКЛ / ВЫКЛ | Клавиша `F3` или кнопка `▶ Симулятор` | Кнопка `▶ Симулятор (F3)` |
| Отмена / Повтор / Удаление | `Ctrl+Z`, `Ctrl+Y`, `Delete`, `Ctrl+C`, `Ctrl+V`, `Ctrl+S` | Кнопки на верхней панели |

## 🛠 Разработка и сборка из исходного кода

```bash
# Установка зависимостей
npm install

# Запуск автоматических тестов ПЛК-ядра и проверяющей системы практикума
npm test

# Запуск веб-версии в режиме разработки
npm run dev

# Сборка оффлайн-бандла и компиляция подписанного Android APK
npm run build:apk
```
